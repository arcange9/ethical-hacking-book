# Appendix D — CYBERSECURITY GLOSSARY

*Designed by Mukamyi Izere Arcange*

---

**Authentication** — Proving who you are (username + password, biometrics, tokens)

**Authorization** — What you're allowed to do after authenticating (permissions, roles)

**Access Control** — Rules that determine who can access what resources

**API** — Application Programming Interface; how programs talk to each other

**APT** — Advanced Persistent Threat; long-term, sophisticated attacker (often nation-state)

**Attack Surface** — All possible points where an attacker could try to enter

**Banner Grabbing** — Connecting to a service and reading its identification string

**Bind Shell** — A shell where the target listens and the attacker connects to it

**Blue Team** — Defensive security team that protects systems and responds to incidents

**Botnet** — A network of compromised computers controlled remotely by an attacker

**Brute Force** — Trying every possible password/key until the correct one is found

**C2 (Command & Control)** — Server that attackers use to control compromised systems

**Certificate** — Digital document binding a public key to an identity, signed by a CA

**CIDR** — Classless Inter-Domain Routing; notation for network size (e.g., /24)

**CIA Triad** — Confidentiality, Integrity, Availability; core security principles

**Cookie** — Small piece of data stored in the browser to identify sessions

**CVE** — Common Vulnerabilities and Exposures; standardized vulnerability identifier

**CVSS** — Common Vulnerability Scoring System; scores severity 0-10

**Daemon** — Background process running continuously on a system

**DDoS** — Distributed Denial of Service; overwhelming a target with traffic from many sources

**DHCP** — Dynamic Host Configuration Protocol; assigns IP addresses automatically

**DNS** — Domain Name System; converts names to IP addresses

**Domain Controller** — Server running Active Directory that authenticates users

**EDR** — Endpoint Detection and Response; advanced endpoint monitoring

**Encryption** — Converting data to unreadable form using a key (two-way, reversible)

**Enumeration** — Extracting detailed information about services and users

**Exploit** — Code or technique that takes advantage of a vulnerability

**Exploit Chain** — Multiple exploits used in sequence to achieve an objective

**Firewall** — Network security device that filters traffic based on rules

**FTP** — File Transfer Protocol; transfers files (unencrypted)

**GPO** — Group Policy Object; central configuration in Active Directory

**Hash** — One-way fingerprint of data; same input always gives same output

**HTTP** — Hypertext Transfer Protocol; how web pages are transferred

**HTTPS** — HTTP Secure; HTTP with TLS encryption

**ICMP** — Internet Control Message Protocol; used for ping and diagnostics

**IDOR** — Insecure Direct Object Reference; accessing resources by changing IDs

**IOC** — Indicator of Compromise; artifact showing a system was attacked

**IP Address** — Unique network identifier for a device (IPv4 or IPv6)

**Kerberos** — Network authentication protocol using tickets

**Kerberoasting** — Attack that extracts and cracks service account tickets

**Lateral Movement** — Moving from one compromised system to others on the network

**LDAP** — Lightweight Directory Access Protocol; queries directory services

**Least Privilege** — Giving users only the minimum access they need

**MAC Address** — Physical hardware identifier for a network card

**Malware** — Malicious software (virus, worm, trojan, ransomware, spyware)

**Meterpreter** — Advanced Metasploit payload with many post-exploitation features

**MITRE ATT&CK** — Framework mapping attacker tactics and techniques

**MFA** — Multi-Factor Authentication; using two or more verification methods

**NAT** — Network Address Translation; sharing one public IP among private devices

**Nmap** — Network Mapper; the primary network scanning tool

**Nonce** — Number used once; prevents replay attacks

**OSINT** — Open Source Intelligence; gathering info from public sources

**OSI Model** — 7-layer networking framework (Physical to Application)

**Payload** — Code that runs after a vulnerability is exploited

**Penetration Testing** — Authorized simulated attack on a system to find weaknesses

**Phishing** — Fraudulent emails pretending to be legitimate to steal credentials

**Ping** — ICMP echo request to test if a host is reachable

**Port** — Number identifying a specific service on a device (80=HTTP, 22=SSH)

**Privilege Escalation** — Gaining higher access than currently authorized

**Protocol** — Set of rules for how data is formatted and transmitted

**Proxy** — Intermediary that forwards traffic between client and server

**Purple Team** — Red and Blue teams working together to improve both sides

**Ransomware** — Malware that encrypts data and demands payment for decryption

**Reconnaissance** — Information gathering about a target before attacking

**Red Team** — Offensive security team that simulates attacks

**Reverse Shell** — A shell where the target connects back to the attacker's listener

**RDP** — Remote Desktop Protocol; remote graphical access to Windows

**Rootkit** — Malware that hides deep in the OS at root level

**Salt** — Random data added to a password before hashing to prevent rainbow tables

**Sandbox** — Isolated environment for safely running and analyzing malware

**Session** — A period of authenticated interaction between client and server

**SIEM** — Security Information and Event Management; log correlation and analysis

**SMB** — Server Message Block; Windows file sharing protocol

**SMTP** — Simple Mail Transfer Protocol; sends email

**SNMP** — Simple Network Management Protocol; manages network devices

**SOC** — Security Operations Center; team that monitors and responds to threats

**Social Engineering** — Manipulating people into revealing info or performing actions

**Sploit** — Slang for exploit

**SQL Injection** — Manipulating database queries through unsanitized input

**SSH** — Secure Shell; encrypted remote terminal access

**SSID** — Service Set Identifier; Wi-Fi network name

**SSL/TLS** — Secure Sockets Layer / Transport Layer Security; encryption for data in transit

**STRIDE** — Threat model: Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation

**Subnet** — A subdivision of a larger network

**TCP** — Transmission Control Protocol; reliable, connection-oriented protocol

**Threat Intelligence** — Information about threats, threat actors, and their methods

**Token** — A piece of data used for authentication or session tracking

**Trojan** — Malware disguised as legitimate software

**TTP** — Tactics, Techniques, and Procedures; how attackers operate

**UDP** — User Datagram Protocol; fast, connectionless protocol

**Vishing** — Voice phishing; phishing over phone calls

**VPN** — Virtual Private Network; secure tunnel through untrusted networks

**Vulnerability** — A weakness in a system that could be exploited

**WEP** — Wired Equivalent Privacy; broken Wi-Fi security protocol (never use)

**WPA2** — Wi-Fi Protected Access 2; common Wi-Fi security using AES-CCMP

**WPA3** — Wi-Fi Protected Access 3; current best Wi-Fi security standard

**XSS** — Cross-Site Scripting; injecting malicious JavaScript into web pages

**Zero Trust** — Security model: never trust, always verify every access

**Zone Transfer** — DNS server sharing all its records (can leak info if allowed)
