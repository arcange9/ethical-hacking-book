## Certifications to Consider

```
Beginner:
  CompTIA Security+
  CompTIA Network+
  eJPT (eLearnSecurity Junior Penetration Tester)

Intermediate:
  CompTIA PenTest+
  eCPPT (eLearnSecurity Certified Professional Penetration Tester)
  PNPT (Practical Network Penetration Tester)

Advanced:
  OSCP (Offensive Security Certified Professional)
  eWPTX (Web Penetration Testing eXtreme)
  CRTO (Certified Red Team Operator)
  GREM (GIAC Reverse Engineering Malware)
  GCFA (GIAC Certified Forensic Analyst)
  CISSP (Certified Information Systems Security Professional)
```

## Practice Platforms

```
HackTheBox — https://www.hackthebox.com
  → Realistic vulnerable machines
  → Progressive difficulty
  → Active and retired machines

TryHackMe — https://www.tryhackme.com
  → Guided learning paths
  → Beginner-friendly rooms
  → Interactive exercises

PortSwigger Web Security Academy — https://portswigger.net/web-security
  → Free web security training
  → Created by Burp Suite makers
  → Comprehensive OWASP coverage

CyberDefenders — https://cyberdefenders.org
  → Blue team challenges
  → Incident response scenarios
  → Log analysis practice

PicoCTF — https://picoctf.org
  → Beginner CTF challenges
  → Free, educational
  → Great for learning
```
