# ETHICAL HACKING: From Computer Basics to Advanced Cybersecurity

*Designed by Mukamyi Izere Arcange*

A practical, beginner-to-advanced guide to ethical hacking and cybersecurity using Kali Linux & VirtualBox. 19 progressive levels, from computer fundamentals through advanced penetration testing and blue team operations.

## Safety & Ethics

All practical exercises are designed for **isolated, learner-owned laboratory environments only**. Never test techniques on systems you do not own or do not have explicit written authorization to test.
